# تحليل مبيعات متجر التجزئة باستخدام Excel

## نظرة عامة على المشروع
يهدف هذا المشروع إلى تحليل بيانات مبيعات متجر تجزئة باستخدام Microsoft Excel، لفهم أداء المبيعات والأرباح، ومقارنة فئات المنتجات والمناطق الجغرافية وشرائح العملاء. تم إنشاء لوحة معلومات تفاعلية تساعد على متابعة مؤشرات الأداء الرئيسية واستخلاص نتائج تدعم اتخاذ القرارات المبنية على البيانات.

## الأدوات والتقنيات المستخدمة
- Microsoft Excel
- Power Query لتنظيف البيانات وتحويلها
- Power Pivot لنمذجة البيانات
- DAX لإنشاء المقاييس الحسابية
- PivotTables وPivotCharts لتحليل البيانات وعرضها
- Interactive Slicers لتصفية البيانات داخل لوحة المعلومات

## وصف مجموعة البيانات
تحتوي مجموعة بيانات Sample Superstore على معاملات مبيعات متجر تجزئة خلال الفترة من 2014 إلى 2017.

- **عدد السجلات:** 9,994 سجلًا
- **عدد الأعمدة:** 21 عمودًا
- **الفترة الزمنية:** من 2014 إلى 2017
- **أهم الحقول:** تاريخ الطلب، المبيعات، الأرباح، الكمية، الخصم، فئة المنتج، الفئة الفرعية، المنطقة، شريحة العملاء، ومعرّف العميل.

## تجهيز البيانات
تم تجهيز البيانات باستخدام Excel وPower Query من خلال الخطوات التالية:

- استيراد مجموعة البيانات إلى Excel.
- فحص جودة البيانات والتحقق من القيم المفقودة والسجلات المكررة.
- إزالة السجلات المكررة بالاعتماد على Row ID.
- مراجعة أنواع البيانات والتأكد من ملاءمتها للتحليل.
- تحميل البيانات إلى نموذج البيانات في Excel لإجراء التحليلات وإنشاء المقاييس الحسابية.

## التحليلات الموجودة في لوحة المعلومات

1. **اتجاه المبيعات عبر الزمن:** تحليل المبيعات السنوية ومتابعة التغير في الأداء خلال فترة الدراسة.
2. **المبيعات حسب فئة المنتج:** مقارنة أداء Furniture وOffice Supplies وTechnology.
3. **الأرباح حسب الفئة الفرعية:** تحديد الفئات الفرعية الأكثر ربحية والفئات التي تحقق خسائر.
4. **المبيعات حسب المنطقة:** مقارنة أداء المناطق الجغرافية الأربع.
5. **المبيعات حسب شريحة العملاء:** تحليل مساهمة شرائح Consumer وCorporate وHome Office في إجمالي المبيعات.

تتيح أدوات التصفية التفاعلية إمكانية استكشاف البيانات وفقًا لمعايير مختلفة، مما يساعد على فهم تفاصيل الأداء بسهولة.

## أهم النتائج (Key Insights)

1. **أفضل أداء سنوي:** حقق عام 2017 أعلى مبيعات سنوية بقيمة تقارب 733 ألف دولار، كما سجل أعلى أرباح سنوية بقيمة تقارب 93.4 ألف دولار.

2. **تفوق فئة Technology:** حققت هذه الفئة أعلى مبيعات بقيمة تقارب 836 ألف دولار، وأعلى أرباح بقيمة تقارب 145 ألف دولار.

3. **تفوق منطقة West:** سجلت منطقة West أعلى مبيعات بقيمة تقارب 710 آلاف دولار، وأعلى أرباح بقيمة تقارب 108 آلاف دولار.

4. **شريحة Consumer في الصدارة:** حققت هذه الشريحة مبيعات بقيمة تقارب 1.16 مليون دولار، متقدمة على شريحتي Corporate وHome Office.

5. **الخسائر في الفئات الفرعية:** سجلت فئة Tables أكبر خسارة بقيمة تقارب 17.7 ألف دولار، تليها Bookcases بخسارة تقارب 3.5 آلاف دولار.

## التوصيات العملية (Business Recommendations)

1. **تحسين استراتيجية الخصومات:** تحليل العلاقة بين مستويات الخصم والربحية، بهدف تحديد فرص زيادة هامش الربح وتقليل تأثير الخصومات المرتفعة.

2. **مراجعة المنتجات التي تحقق خسائر:** دراسة الأسعار والتكاليف وسياسات الخصم الخاصة بفئتي Tables وBookcases، للوصول إلى حلول تساعد على تقليل الخسائر وتحسين الربحية.

3. **الحفاظ على الأداء القوي لفئة Technology:** الاستمرار في دعم هذه الفئة مع متابعة هوامش الربح وتحديد فرص النمو المستدام.

4. **الاستفادة من نجاح منطقة West:** دراسة أسباب تفوق المنطقة وتقييم إمكانية تطبيق الممارسات الناجحة في المناطق الأخرى.

5. **تطوير استراتيجيات شرائح العملاء:** الحفاظ على الأداء القوي لشريحة Consumer، مع دراسة فرص زيادة المبيعات لدى شريحتي Corporate وHome Office.

## الخلاصة
يوضح هذا المشروع كيفية استخدام Excel وPower Query وPower Pivot وDAX لتحويل بيانات المبيعات إلى معلومات مفيدة تدعم القرارات التجارية. وتوفر لوحة المعلومات التفاعلية رؤية واضحة للمبيعات والأرباح وأداء المنتجات والمناطق وشرائح العملاء، مع تحديد فرص التحسين والتحديات التي تحتاج إلى معالجة.

- تنظيف البيانات وتحويلها.

- التحليل الاستكشافي للبيانات.
- تصميم لوحات المعلومات والتصورات البيانية.
- استخلاص النتائج والتوصيات التجارية.
